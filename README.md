If you downloaded from the Google Drive, you will have to extract the rar file. Move the folder to a location you will remember.

### Fix for the torrent ONLY

**Only do this if you downloaded the torrent**. Go to where you saved the files and to \Dread Hunger\DreadHunger\Binaries\Win64

Delete the file named Overlay.dll

## Translating the Game

This is a Russian torrent... so the game will be in Russian. This is simple to fix:

Go to where you installed the game, then ...\Dread Hunger\DreadHunger\Binaries\Win64
Locate the file named SteamFix.ini and edit it in notepad.

On the line with "Language=russian", change it to "language=english" and save.

## Launching the Game

1. Make sure that Steam is running in the background
2. Launch the game by going to the game folder and double clicking on DreadHunger.exe
   1. You may show on Steam as being in a game called "Spacewar". This is normal. The game is using that testing game to let you use Steam services.
3. Enjoy!

### Limitations

You won't be able to join a game by clicking on someone's steam invite. But that's okay. If someone invites you to a game, simply launch the game as normal and join the open lobby from the table.
